前端设计风格指南

> 基于对目标网站的视觉语言、动效体系及交互细节的深入分析整理而成。  
> 旨在复现其 **沉浸式、流畅、富有科技感** 的用户体验。

---

## 1. 设计理念

- **未来感与轻量化**：通过玻璃态材质、微光效与细腻的阴影，营造通透、轻盈的视觉层次。
- **沉浸式浏览**：大量使用全屏区块、视差滚动与动态背景（粒子/视频），引导用户聚焦内容。
- **动态细节驱动**：每个交互（悬停、滚动、点击）都配有平滑过渡与有意义反馈，增强操作感知。
- **响应式优先**：所有动画与布局在移动端与桌面端保持一致的优雅表现。

---

## 2. 色彩系统

| 类型 | 色值 (HEX/RGBA) | 用途 |
|------|----------------|------|
| 主背景 | `#0A0A0F` | 页面全局底色，深色基底突显科技感 |
| 次要背景 | `rgba(20, 20, 30, 0.7)` | 玻璃卡片、半透明面板 |
| 强调色 | `#5F6CFF` → `#C85CFF`（渐变） | 按钮、关键图标、高亮边框 |
| 辅助色 | `#00E5FF` | 悬浮光效、文字点缀 |
| 正文主色 | `#E8EDFF` | 高可读性的冷白浅色 |
| 正文副色 | `#8E94B0` | 注解、次要说明文字 |
| 成功/警示 | `#2BD67B` / `#FF476C` | 状态反馈 |

> 💡 **实际提取**：可使用浏览器开发工具（F12 → 检查元素 → 计算后样式）获取精确色值。

---

## 3. 字体与排版

- **英文字体**：`'Inter', 'SF Pro Display', 'Helvetica Neue', sans-serif`  
  （无衬线，大写数字，高x-height保证移动端可读性）
- **中文字体**：`'MiSans', 'PingFang SC', 'Microsoft YaHei', sans-serif`  
  （小米生态通用字体，圆润且现代）
- **字重**：  
  - 标题：600 / 700  
  - 正文：400  
  - 强调文本：500
- **字号比例**（基于rem，基准16px）：
  - 超大标题：`clamp(3rem, 8vw, 6rem)` 动态缩放
  - 区域标题：`2.5rem` (桌面) / `1.75rem` (移动)
  - 正文：`1rem`  
  - 小号字：`0.875rem`

- **行高**：标题 `1.2`，正文 `1.5`，代码/标签 `1.3`

---

## 4. 布局与网格

- **容器最大宽度**：`1440px`，两侧留白 `clamp(16px, 5vw, 80px)`
- **栅格系统**：12列网格，间隙 `24px`（移动端 `16px`）
- **区块间隔**：垂直间距使用8px倍率（`24px, 48px, 80px, 120px`）
- **常见模式**：
  - 全屏英雄区（Hero） + 滚动揭示内容
  - 非对称卡片组合（破形布局）
  - 悬浮式侧边栏 / 底部动作面板（移动端）

6. 动画与过渡系统
6.1 运动曲线
标准缓动：cubic-bezier(0.2, 0.9, 0.4, 1.1) → 弹性但不过分夸张

进入/退出：cubic-bezier(0.0, 0.0, 0.2, 1) (Material 标准减速)

滚动触发：cubic-bezier(0.25, 0.46, 0.45, 0.94)

6.2 时长规范
动作类型	持续时间
微交互 (hover/focus)	150–200ms
元素切换/展开	250–350ms
页面转场 / 模态框	400–500ms
滚动视差 / 背景移动	线性 (根据滚动速度)
6.3 典型动效实现
1) 滚动揭示动画 (Intersection Observer)
元素初始：opacity: 0; transform: translateY(30px);

进入视口：opacity: 1; transform: translateY(0); + 过渡 0.6s

2) 悬浮视差层
鼠标移动时，背景/装饰物以 translate 相反方向移动（速度因子：主内容0.02，背景0.01）

3) 页面加载序列动画
骨架屏 → 内容淡入（0.3s 延迟，依次展示卡片）

7. 交互与状态反馈
控件	默认态	悬停/聚焦	激活态	禁用态
按钮	渐变背景，平滑阴影	外发光 + 上浮2px	缩小至0.98 + 阴影减弱	透明度0.5，无交互
输入框	透明底，下划线/浅色边框	边框转为强调色 + 微弱光晕	保持强调色 + 轻微内阴影	透明度0.6
卡片	玻璃背景，无阴影	阴影增强，边框光效	点击时轻微缩小	—
链接/文字	默认色 #8E94B0	颜色变为 #00E5FF + 下划线动画	瞬间回弹	灰色不可选
8. 响应式与性能适配
断点：

移动：< 640px

平板：641px – 1024px

桌面：> 1025px

移动端动画裁剪：
对于低性能设备（通过@media (prefers-reduced-motion: reduce)）降低或移除视差/复杂过渡，保证流畅滚动。

图片/视频懒加载：所有非首屏媒体使用 loading="lazy" 或 Intersection Observer。

GPU加速：对 transform 与 opacity 动画启用 will-change（仅按需使用，适时移除）。

9. 设计资源与实现建议
9.1 推荐技术栈
样式：Tailwind CSS + 自定义CSS变量（基于设计令牌）

动画库：GSAP (滚动触发动画) + Framer Motion (React复杂过渡)

滚动视差：Rellax 或 原生Intersection Observer + transform: translateY()

背景效果：Three.js (粒子系统) 或 Vanta.js

9.2 关键CSS自定义属性
css
:root {
  --color-bg-primary: #0A0A0F;
  --color-bg-glass: rgba(20, 20, 30, 0.55);
  --color-brand: linear-gradient(135deg, #5F6CFF, #C85CFF);
  --transition-smooth: cubic-bezier(0.2, 0.9, 0.4, 1.1);
  --shadow-glow: 0 0 15px rgba(95,108,255,0.5);
}
9.3 快速原型验证
克隆该风格指南到项目中，使用CSS变量覆盖基础样式。

按需引入 @import 或配置构建工具。

逐步实现组件并套用动效类名（如 .reveal-on-scroll， .hover-lift）。

  const x = e.clientX - rect.left;
  const y = e.clientY - rect.top;
  card.style.setProperty('--x', `${x}px`);
  card.style.setProperty('--y', `${y}px`);
});
